6  Computational reproducibility

Demonstration · renv, Docker and Binder

6.1 Learning objectives

By the end of this demonstration, you should be able to explain what the project’s R lockfile records, how a Docker image becomes your MyBinder session, and why we keep a record of the environment used to run an analysis.

6.2 Why this matters

The same script can behave differently when package versions or system libraries change. We need to describe the environment alongside the code and the data version.

Layer What we record Tool or file
R runtime R version renv.lock, runtime information, container base image
R packages Package versions and sources renv and renv.lock
Wider environment Operating-system libraries and rendering tools Dockerfile and image
Code and configuration The revision used for the run Git commit
Actual session Versions loaded when the analysis ran sessionInfo()

renv restores the R packages described by a lockfile. A Docker image can also include the R interpreter, operating-system libraries, and rendering tools. Binder starts a container from such an image in a browser.

6.3 Inspect the R environment

We can next view the contents of the renv.lock file:

file.edit("renv.lock")

The version of R running with your environment should ideally match the lock file.

source("pipelines/workshop_support.R")
use_workshop_book_outputs()

R.version.string
[1] "R version 4.4.1 (2024-06-14)"
packageVersion("renv")
[1] '1.0.7'

Compare the running version with the reference version, 4.4.1. A lockfile records a version; it does not switch your running R session.

lock <- renv::lockfile_read("renv.lock")
lock$R$Version
[1] "4.4.1"
workshop_packages <- c(
  "dataspice", "meta", "pins", "rfair", "rmarkdown",
  "synthpop", "targets", "vetiver"
)
vapply(
  workshop_packages,
  function(package) {
    record <- lock$Packages[[package]]
    if (is.null(record)) NA_character_ else record$Version
  },
  character(1)
)
dataspice      meta      pins     rfair rmarkdown  synthpop   targets   vetiver 
  "1.2.1"   "9.0-0"   "1.4.2"   "0.2.0"    "2.32"   "1.9-3"  "1.12.0"   "0.2.8" 
renv::status()
No issues found -- the project is in a consistent state.

The lockfile records exact package versions for the workshop. renv::status() checks whether the active library matches the lockfile.

The usual collaboration cycle is:

  1. A maintainer prepares and tests the required packages.
  2. The maintainer uses renv::snapshot() and reviews the resulting lockfile.
  3. Collaborators use renv::restore() to obtain the recorded packages.
  4. The analysis is tested in the restored environment.

The workshop’s Binder image was built by restoring this lockfile, so you do not need to run renv::restore() during the session.

6.4 From a Dockerfile to RStudio on MyBinder

6.4.1 Read the Dockerfile

A Dockerfile is a set of instructions for building a Docker image. Find these instructions in the workshop’s Binder image Dockerfile.

Instruction What it does in this project
FROM rocker/binder:4.4.1 AS base Starts from Rocker’s Binder image for R 4.4.1.
RUN Executes build steps such as installing system libraries and restoring R packages from renv.lock.
COPY Adds files such as the lockfile and workshop lessons to the image.

A Docker build uses these instructions and the repository files to produce an image. A container is a running instance of an image. Each participant runs the workshop in their own container started from the same image.

6.4.2 Launch the published environment

MyBinder prepares the launch image and starts a container on its servers. Because everyone starts from the same image, everyone has the same R version, packages, and tools for the hands-on activities.

6.5 Record the session

View and record the details of the current R session.

raw_file <- file.path("data", "raw", "healthwellbeing.rda")
stopifnot(
  file.exists(raw_file),
  identical(
    unname(tools::md5sum(raw_file)),
    "0d74964b0b7168379a2b015cb648b326"
  )
)
data_env <- new.env(parent = baseenv())
loaded_names <- load(raw_file, envir = data_env)
stopifnot(identical(loaded_names, "HealthWellbeing"))
health <- data_env[["HealthWellbeing"]]
stopifnot(nrow(health) == 29L, ncol(health) == 5L)

source("pipelines/workshop_support.R")
