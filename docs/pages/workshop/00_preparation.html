4  Preparation

Before the session · MyBinder

4.1 Learning objectives

We will use MyBinder for this workshop. You should be able to open the prepared workshop environment, load a verified copy of the teaching data, and prepare the dataset versions used in the hands-on activities. You will use the same project, dataset, and environment throughout the workshop.

4.2 Our teaching dataset

We use HealthWellbeing from the correlations chapter (Harrer et al. 2021, sec. 4.2.4). It contains study-level summaries of the association between health and well-being. It is also distributed with the dmetar package.

The original review is Ngamaba, Panagioti, and Armitage (2017). The dataset documentation describes the variables (Harrer et al., n.d.).

4.3 Open the prepared environment

MyBinder runs the workshop’s published image in your browser, with RStudio, R 4.4.1, Git, Quarto, and the R packages recorded in the project lockfile already installed. There is nothing to install during the workshop.

  1. Open RStudio on MyBinder or use the link supplied by your instructor. Start it shortly before the workshop and keep the browser tab open; MyBinder stops idle sessions.
  2. MyBinder sessions are temporary. Export any important work before closing your session.

4.4 Check the project

You do not need to clone anything. MyBinder opens RStudio with the workshop project already in your home folder, /home/rstudio. This folder is the project root: the Files pane shows pages, pipelines, data, and open-and-reproducible-science-in-r.Rproj. The lessons’ paths, such as pipelines/prepare_health_wellbeing.R, are relative to this folder, so run every command from here.

The project’s .Rprofile activates renv. Check your R version and whether the library matches the lockfile. If the library in your MyBinder session differs from the lockfile, check with the instructor before proceeding.

source("pipelines/workshop_support.R")
use_workshop_book_outputs()

R.version.string
[1] "R version 4.4.1 (2024-06-14)"
renv::status()
No issues found -- the project is in a consistent state.

4.5 Verify the raw data

Run the following in the R Console from the project root. This will download and inspect the meta-analysis dataset.

raw_file <- file.path("data", "raw", "healthwellbeing.rda")
source_url <- paste0(
  "https://raw.githubusercontent.com/MathiasHarrer/dmetar/",
  "38c9b9bb5f85ea49de33e5d2536f6544d5268517/data/HealthWellbeing.rda"
)

dir.create(dirname(raw_file), recursive = TRUE, showWarnings = FALSE)
if (!file.exists(raw_file)) {
  download.file(source_url, destfile = raw_file, mode = "wb")
}

data_env <- new.env(parent = baseenv())
loaded_names <- load(raw_file, envir = data_env)
stopifnot(identical(loaded_names, "HealthWellbeing"))
health <- data_env[["HealthWellbeing"]]

source(file.path("pipelines", "prepare_health_wellbeing.R"))

4.6 Preparation checkpoint

You are ready when:

  • RStudio is open in MyBinder, or in your own prepared setup, at the project root.
  • You know your R version and renv::status() reports no problems.
  • The meta-analysis dataset is downloaded.
